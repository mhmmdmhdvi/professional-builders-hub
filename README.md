# Professional Builders Hub

Build a single-page, premium Customer Club landing page for an adhesive company.

Core Requirements

Language: Persian (Farsi)

Layout direction: RTL

This is only a landing page — do not create dashboards, authentication pages, or extra pages.

The design must feel like a professionally designed modern corporate website, not a generic AI-generated landing page.

Focus on high-quality typography, spacing, visual hierarchy, subtle animations, and polished components.

Fully responsive, with excellent mobile and desktop experiences.

Target Audience

The Customer Club is designed for professionals who work with construction adhesives and installation materials, including:

پیمانکاران ساختمانی

نصابان اسلب و سرامیک

کاشی‌کاران

مجریان پروژه‌های ساختمانی

فروشندگان و فعالان حوزه ساختمان

متخصصانی که به صورت حرفه‌ای از محصولات چسب و مواد ساختمانی استفاده می‌کنند

The platform should feel exclusive, professional, and valuable, encouraging professionals to join the club and participate in its community and events.

Brand Feel

Create a visual identity that feels:

Professional

Premium

Modern

Trustworthy

Industrial but elegant

Community-oriented

Avoid:

Generic SaaS landing page layouts

Excessive gradients

Overused glassmorphism

Huge rounded cards everywhere

Random floating blobs

Excessive animations

Generic AI illustrations

Use a clean modern design system with strong typography, intentional whitespace, subtle borders, refined shadows, and high-quality visual composition.

The website should look like something a real professional design agency created for a major construction materials brand.

Header / Navigation

Create a clean sticky header.

RTL navigation items:

رویدادها

درباره ما

تماس با ما

ورود

Make ورود visually distinct as a button or premium outlined CTA.

Include a placeholder logo area on the right side.

The header should be elegant and minimal, with smooth scrolling to the corresponding landing page sections.

Hero Section

Create a visually powerful hero section introducing the Customer Club.

Main concept:

باشگاه مشتریان؛ جایی برای حرفه‌ای‌ها

Suggested supporting text:

«باشگاه مشتریان ما، جامعه‌ای تخصصی برای پیمانکاران، نصابان و فعالان حرفه‌ای صنعت ساختمان است؛ جایی برای یادگیری، ارتباط، تجربه فرصت‌های جدید و بهره‌مندی از مزایای ویژه.»

Include two CTA buttons:

Primary:
عضویت در باشگاه

Secondary:
مشاهده رویدادها

The hero should include strong visual elements related to:

Construction

Professional installers

Large-format slabs

Ceramic installation

Adhesives

Architecture

Professional craftsmanship

Use a sophisticated composition rather than simply placing a stock image beside text.

Why Join Us Section

Create a premium section explaining the value of joining the Customer Club.

Title:

چرا به باشگاه مشتریان بپیوندید؟

Create 4–6 benefit cards or an alternative sophisticated layout.

Possible benefits:

رویدادهای تخصصی

شرکت در رویدادها، ورکشاپ‌ها و برنامه‌های تخصصی صنعت ساختمان.

آموزش و یادگیری

دسترسی به آموزش‌ها و تجربه‌های تخصصی برای ارتقای مهارت‌های حرفه‌ای.

ارتباط با متخصصان

فرصتی برای شبکه‌سازی و ارتباط با دیگر فعالان حرفه‌ای صنعت.

مزایای ویژه

دسترسی به فرصت‌ها، خدمات و مزایای اختصاصی اعضای باشگاه.

اطلاع از محصولات جدید

اولین نفری باشید که با محصولات و تکنولوژی‌های جدید آشنا می‌شوید.

جامعه حرفه‌ای

عضویت در جامعه‌ای از متخصصان، پیمانکاران و نصابان حرفه‌ای.

Do not make these look like basic icon cards. Use a refined editorial layout with subtle visual hierarchy.
